# 商业模型

> 写给接手的人：**技术决策要能追溯到这里。**
> 「免费层为什么不能设限制」「为什么全部 Apache-2.0」「为什么先做文件关联」——
> 答案都在这份文档里，别凭直觉推翻。

## 先承认一件事：压缩软件本身不赚钱了

| | 结局 |
|---|---|
| WinZip | 被 Windows 内置 zip 打死，几经转手 |
| 7-Zip | 装机量巨大，收入接近零 |
| WinRAR | 靠「永不过期的试用」+ 企业合规采购，是惯性不是产品力 |
| 国内快压/好压/2345 | 靠捆绑和导航页，把整个品类的口碑烧掉了 |

所以「成为 AI 时代的 WinRAR」是**分发策略，不是收入模型**。
真正的问题是：装机量兑现成什么。

## 答案：AI 那一层是真花钱的，而收银台已经有了

**预览解压是零边际成本，AI 改写是真花钱。**

实测：codex 改一个几行的 markdown 用了 **17,839 tokens**。真实合同 / PPT 会大一个量级。

这意味着 AI 那一层收费**不是设卡收过路费，是成本回收**。
2026 年的用户完全接受「AI 要花钱」，但完全不接受「解压要花钱」。

而虾盘云（`~/Desktop/claude/u-claw/虾盘云==api中装分发和官网/`）已经是在跑的
AI API 分发平台：有充值、有 token key、有 CLI、有服务器。这不是要建的能力，是现成的收银台。

## 四层结构，钱只在下面两层

| 层 | 内容 | 收费 | 作用 |
|---|---|---|---|
| **0 免费永久** | 打开任意格式 + 解压 + 标注 | 白送，不要账号 | 这层负责「每台电脑都有」 |
| **1 自带 key** | 用用户自己的 Claude Code / Codex | 白送 | **已实现**。开发者白用，他们是传播者 |
| **2 一键 AI** | 不装任何 CLI，直接改 | 虾盘云计量 | 90% 的人在这层，主要收入 |
| **3 企业** | 私有部署 / 审计 / 策略 / 批量 | 年费席位 | 毛利最高 |

### 第 1 层白送是关键，别舍不得

它让 Redline 在技术圈站得住（「不绑架你，你有 key 就用你的」），
而这批人的背书决定第 0 层能不能铺开。

### 第 3 层的东西已经建了一半

`document.apply-track-changes` 输出的审计记录——输入 sha256、输出 sha256、作者、
逐条改动、回滚说明——就是合规凭证。版本图（P3）的每条连线也是。

企业真正买的是这个 + **私有部署**（合同不能出网）。这是刚需，不是加价项。

## License：全部保持 Apache-2.0，别拆

直觉是「桌面端闭源，防止别人做去广告版」。但护城河不在那儿：

**fork 出来的客户端，唯一能剥掉的是第 2 层的付费 UI。而第 2 层的 key 在服务端。**
剥掉付费 UI 的 fork ≠ 白嫖 AI，只等于回到第 1 层——那本来就免费。

所以闭源换不到任何保护，却换掉了更大的目标：
**成为「AI 操作文档」的事实标准协议**。要让别的 agent 项目和大厂放心嵌入 MCP，
Apache-2.0（带专利授权条款）是必要条件。

**只有企业侧的审计服务端 / 策略管理另开私有仓。**

## 冷启动：别用 AI 打

这条最重要，也最反直觉。

**没人会为了 AI 去换压缩软件。** 但很多人每天被这个折磨：
收到 `.psd` 打不开、`.dxf` 打不开、`.pptx` 要装 Office、`.rar` 要装 WinRAR、
扫描件 PDF 看不了文字。

所以第一句话是「**什么都能打开，一个软件都不用装**」，
AI 是打开之后自然出现的下一步。等用户在预览里看到那条「要不要让 AI 改一下」，转化才发生。

反过来打「AI 文档助手」，面对的是 WPS 灵犀、微软 Copilot、Neo——最拥挤的赛道；
打「万能打开器」，面对的是 7-Zip 和一堆国产捆绑流氓。

**这直接决定了工程优先级**：格式覆盖广度不是杂活，是主线。

## 分发渠道

除了常规下载，有两个别人没有的：

- **U 盘**：U-Claw 已经在淘宝卖实体盘，Redline 搭车零成本。
  而且 U 盘用户恰好是最需要「没装软件也能打开文件」的那批人
- **已有装机**：U-King / OpenCodex 的客户机

## 三条不要（写进代码约束）

1. **不要捆绑安装、导航页、nag 弹窗。** 国内这个品类就是这么死的。
   「永远干净」是真实差异化，要写进 README 当承诺
2. **不要在有装机量之前做企业版。** 卖不动
3. **不要给免费层设使用次数。** 解压是水电，一收费用户立刻换回 7-Zip，
   连上桌机会都没有

## 最大的风险

Anthropic 的 Claude Design 如果延伸到文档场景，会直接吃掉这块差异化；
微软已经在 Word 里做评论驱动修订。（这两条在 2026-07 的竞品调研里就点到了。）

**防线不是技术，是格式广度 + 装机惯性。**
大厂不会去支持 PSD、DXF、STL、RAR——那些对他们不划算，
但恰恰是「什么都能打开」这句话成立的关键。

所以：**格式覆盖就是护城河本身**，别当成体力活外包掉就不管质量。

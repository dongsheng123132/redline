# 传播计划

> 传播目标不是制造一次热度，而是让「文件打不开，先用叠象」成为条件反射。
> 产品没达到[功能与代码规划](./功能与代码规划.md)的发布门槛前，不做大规模投放。

## 1. 传播定位

### 第一层：用户为什么下载

> **什么文件都能先打开，一个原软件都不用装。**

备选短句：

- 文件打不开，先用叠象；
- 一个软件，先看懂电脑里的所有文件；
- 不装 Office、PS、CAD，也能先看内容。

不要第一句话就说：

- AI 文件预览器；
- 多 Agent 无限画布；
- MCP/ActionParity；
- 大模型驱动的新一代生产力平台。

这些都是机制，不是普通用户当下的问题。

### 第二层：为什么留下

> **在文件上直接指出哪里要改，AI 生成新版本，原件永远保留。**

### 第三层：为什么区别于 Claude/ChatGPT

> **Claude、Codex 和本地模型都是可换的发动机；叠象负责文件、版本、对照和安全。**

### 第四层：为什么企业相信

> **本地优先、过程可审计、模型可替换、源文件不覆盖。**

## 2. 30 秒标准演示

所有发布渠道复用同一个可观察脚本，不用口头讲宏大愿景：

1. 在没有 Office/Photoshop/CAD 的干净 Windows 机上；
2. 连续双击打开 zip、docx、PSD、DXF；
3. 在合同或设计稿上圈一个区域，写一句修改要求；
4. 选择 Codex，右侧出现新文件和差异；
5. 表示不满意，回到父版本，换 Claude 生成第二个分支；
6. 最后显示源文件 sha256 未变化。

演示标题：

> **一个打不开的文件，如何变成两个可比较的 AI 版本**

演示必须使用真实发布版和普通用户机器，不能用剪辑掩盖等待、报错或预装依赖。

## 3. 渠道顺序

### 3.1 官方下载与可信分发

1. 官网：唯一稳定的中文下载入口、隐私承诺、格式能力表；
2. GitHub Releases：源码、变更记录、签名产物和 sha256；
3. WinGet：有签名、静默安装/卸载和稳定下载地址后提交；
4. Microsoft Store：安装器和更新链稳定后再上；
5. U-Claw/U-King：只做用户明确选择的附加安装或推荐，不静默捆绑。

Microsoft 的 WinGet 社区仓会自动校验提交的 manifest 和安装包；
Microsoft Store 也允许提交现有 EXE/MSI，但要求安装器只安装用户选择的产品：

- [Microsoft：创建 WinGet manifest](https://learn.microsoft.com/en-us/windows/package-manager/package/manifest)
- [Microsoft：提交 WinGet 包](https://learn.microsoft.com/en-us/windows/package-manager/package/repository)
- [Microsoft：发布 Win32 应用到 Store](https://learn.microsoft.com/en-us/windows/apps/distribute-through-store/how-to-distribute-your-win32-app-through-microsoft-store)
- [GitHub：Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)

### 3.2 开发者传播

- GitHub README：30 秒 GIF、支持格式矩阵、三条安全承诺、五分钟接入；
- 给 Claude Code、Codex 各做一页 MCP/CLI 教程；
- V2EX、即刻、少数派等发布技术与产品复盘，不只贴下载链接；
- Product Hunt、Show HN 面向国际用户时，主打 model-neutral universal file layer；
- 鼓励第三方 Agent 项目把 `redline-mcp` 作为文件工具，而不是嵌入官方云。

### 3.3 视频与普通用户

- B 站：完整真实演示、格式挑战、开发复盘；
- 抖音/视频号：15–30 秒「没装软件也打开」单场景；
- 小红书：办公、投标、设计协作的前后对照图；
- 知乎：为什么 AI 改文件不能覆盖原件、不同 Agent 结果对比；
- 淘宝 U 盘用户：包装卡片和桌面入口，强调免费打开与不捆绑。

同一条内容不要原样搬运。短视频只证明一个惊讶点，长视频再解释版本和 Agent。

## 4. 冷启动的四类内容

### 4.1 格式挑战

每期选一种常见但麻烦的格式：

> 「电脑没装 Photoshop，能不能打开这个 800 MB PSD？」
>
> 「收到 DXF，只想先看尺寸，为什么要先装 CAD？」
>
> 「这个压缩包为什么被叠象拒绝解压？」

既展示成功，也展示安全拒绝。拒绝恶意文件本身就是可信内容。

### 4.2 修改对决

同一份文件、同一组标注，让 Claude、Codex 和本地模型各生成一个分支，
公开比较结果、耗时、成本和差异，不宣布固定赢家。

### 4.3 源文件不变

用可验证方式展示：

- 修改前后源文件 sha256 相同；
- 所有结果是新文件；
- 卸载后文件关联恢复；
- 无网络时仍能打开、标注和解压。

### 4.4 开源建造

- 为什么 Action 只实现一次；
- 如何防 zip-slip；
- 怎样新增一种格式；
- 为什么桌面端开源仍能商业化；
- 每月公开格式成功率、崩溃率和下一批支持计划。

## 5. 发布节奏

### 阶段 A：私测

对象：20–30 名真实文件重度用户，不限开发者。

准备：

- 100–300 个脱敏黄金文件；
- 自动更新或明确的手动更新流程；
- 一键导出诊断包，默认不包含文件内容和文件名；
- 统一反馈模板：文件类型、期望、实际、是否愿意提供脱敏样本。

目标：发现安装、预览和卸载问题，不追求传播量。

### 阶段 B：公开 Alpha

发布资产：

- 一个签名安装包和一个便携版；
- 30 秒主视频；
- 支持格式/能力/限制矩阵；
- 「永不捆绑、源文件不覆盖、本地打开免登录」三条承诺；
- GitHub Issues 模板与安全报告入口。

目标：验证「万能打开」是否形成第二次使用。

### 阶段 C：Agent Beta

前提：P0/P1 稳定，MCP 和 WorkOrder 端到端跑通。

传播重点从「打开」升级为：

> 看完不用另开聊天窗口，圈出来就能让任意 AI 改。

邀请 Agent 开发者制作适配器和工作流，做 Claude/Codex 分支对比活动。

### 阶段 D：版本图发布

无限画布只在真实用户已经发生多轮修改后发布。主视频要展示：

- 向右继续；
- 回到旧版向下分叉；
- 换 Agent；
- 对照两个结果；
- 原分支仍在。

这会成为叠象区别于普通文件预览和聊天 Artifact 的标志性演示。

### 阶段 E：商业化

云 AI 首发只邀请已有自带 key 使用记录的用户，验证「免配置」是否值得付费。
企业内容则用私有部署、策略和审计案例，不用个人效率故事硬卖。

## 6. 产品内传播回路

不做水印和强制分享，传播应来自用户真实产物：

- 一键导出脱敏的版本图截图或交互回放；
- 分享链接默认不含源文件，接收者按权限查看差异；
- 「用叠象打开」只出现在 Windows Open With 和右键菜单，不篡改默认；
- 不支持格式页面允许投票并提交脱敏样本；
- 格式/Agent 插件有作者署名和兼容认证；
- 每份审计报告注明使用的开放协议，方便企业技术人员反向找到项目。

## 7. 落地页结构

首屏只回答三件事：

1. **标题**：什么文件都能先打开，一个原软件都不用装；
2. **动图**：打开 → 标注 → AI → 右侧新版本；
3. **按钮**：免费下载 Windows 版；旁边提供「查看源码」。

后续页面依次是：

1. 格式矩阵，不用 Logo 墙冒充支持；
2. 三条承诺——源文件不覆盖、本地打开免登录、没有捆绑；
3. Claude/Codex/本地模型可替换；
4. 版本分叉演示；
5. 开发者 CLI/MCP；
6. 企业私有部署候补名单。

## 8. 内容计划

在公开 Alpha 后保持最低可持续节奏：

| 频率 | 内容 |
|---|---|
| 每周 | 一个真实格式挑战或用户场景 |
| 每两周 | 一次版本发布和可验证变更记录 |
| 每月 | 格式成功率、崩溃率、安全事件和路线图复盘 |
| 每季度 | 一次 Agent 对决或社区格式开发活动 |

不要每天追热点。文件工具的传播依赖可信、可复现和长期搜索流量。

## 9. 传播指标

| 层 | 指标 | 不要误读 |
|---|---|---|
| 触达 | 视频完成率、官网到达 | 播放量不等于需求 |
| 获取 | 安装包下载、安装成功 | 下载量不等于装机 |
| 激活 | 24 小时内成功打开第二个文件 | 首次打开可能只是尝鲜 |
| 留存 | 第 4 周有效打开设备 | 启动空窗口不算 |
| 传播 | 自然搜索、直接访问、分享回放 | 强制水印带来的点击没有价值 |
| 商业 | 云任务复购、团队试点、企业合同 | 充值余额不等于已实现收入 |

遥测必须选择加入，并默认只记录扩展名类别、耗时、结果码和版本，不记录路径、文件名、
文档正文、标注内容和提示词。用户关闭遥测后，核心功能完全可用。

## 10. 传播红线

- 不宣传「100% 支持所有格式」；
- 不把结构化大纲说成高保真预览；
- 不展示未经许可的客户文件；
- 不用捆绑、默认勾选、浏览器劫持换装机量；
- 不把 Claude/Codex 商标放进产品名或 Logo；
- 不暗示官方合作，除非确有书面授权；
- 不把安全拒绝和模型失败剪掉，保留真实边界；
- 不在叠象/Stelora 商标核验前购买大量物料或做不可逆品牌迁移。

# ShadowDoc 影文档宣言

> 状态：非规范性工作草案，2026-07-31。
> 本宣言解释 ShadowDoc 为什么存在；若与规范正文冲突，以规范正文为准。

## 文件不应只是“能打开”，而应随时“能工作”

文件仍然以 Word、表格、演示文稿、PDF、图片、压缩包以及更多格式来到我们手中。但人们越来越
不想先学会每一种创作软件，才能理解或修改一个文件。人们想先看到内容，指出真正要改的位置，
请 AI agent 帮忙，核对结果，然后继续修改。

今天，这些步骤是断裂的：预览器看到的是像素，agent 收到的是复制出来的文本，批注指向的位置
可能已经移动，生成结果也常常失去与源文件的关系。ShadowDoc 要保住的，正是这条关系。

**ShadowDoc 把不可静默改写的源文件映射成一个或多个可重建、可寻址、可验证的影子层，使人和
AI agent 能围绕同一份意图协作，而不牺牲原件。**

它不是一种新的 Office 文件格式，而是现有与未来格式之上的协作层。

## 协作循环

```text
不可静默改写的源文件
  → 可重建的影子层
  → 人工或机器标注
  → 有明确边界、与模型无关的工单
  → 新的结果文件
  → 可验证的版本节点
  → 继续、对照或分叉
```

源文件始终是权威；影子让内容更容易被看见、定位和处理；标注记录人的意图；agent 产出候选
结果；新文件承载结果。历史可以不断向右延伸，也可以从任意旧版本分叉，不必假装世界上只有一
个“最终版本”。

## 七项原则

### 一、源文件是权威

源文件由它的真实字节确定，而不是只由文件名或路径确定。实现不得静默覆盖源文件；字节一旦
变化，它就是另一个源对象。

### 二、影子因“可丢弃”而可靠

影子层可以包含提取后的结构、文本、视觉坐标、缩略图、OCR 或 AI 辅助理解。它是派生状态，不
是原件；它应说明自己如何产生，并能在生产器升级后重新生成。

### 三、人和 agent 应能指向同一个对象

页面上的圈选、一个单元格、一段文字和一个语义单元，都应落到明确且可验证的锚点。人的意图在
交给 agent 时，不应退化成一段指向不明的提示词。

### 四、每次接受修改都产生一个新版本

Agent 的输出是候选文件，不是对原件的静默修改。每个版本都应保留来源关系、处理过程和验证状
态。用户可以对照、拒绝、继续，也可以从任何版本重新分叉。

### 五、模型和 agent 都可替换

标注和工单属于用户，不属于某一家 AI 厂商。同一份有边界的意图，应能交给本地模型、云端模型
或专用 agent。更换执行者，不应抹掉此前的协作历史。

### 六、打开应该快、本地优先、成本足够低

常见文件应在昂贵的深度转换完成前就可以使用。实现可以渐进呈现更深的结构，只在任务需要时调
用重型解析器、OCR 或 AI。除非用户明确选择，私有源文件的字节应留在本机。

### 七、所有主张都要有可互操作的证据

一个闪光的想法还不是标准。每一项规范性主张都应有 Schema、一致性样例或可独立复现的测试支
撑；性能和质量数据必须说明语料、环境与局限。稳定版需要独立实现，而不只是一个参考产品。

## 与现有生态一起建设

只要适合，ShadowDoc 就应复用成熟的解析器、渲染器和标准词汇。Docling、MarkItDown、PDF 引
擎、Office 类库和 W3C Web Annotation 等，都可以成为生产器、消费者或设计参考。ShadowDoc
要做的是在这些组件之间保存源文件身份、可寻址意图、处理来源和版本关系，而不是取代所有组件。

一个有用的生产器可以只实现很小的 Core Profile。更丰富的视觉、标注、Agent 与 Project
Profile 应保持可拆分，采用者不必先接受一整套平台。

## ShadowDoc 明确不做什么

ShadowDoc 不是：

- 号称可以无损编辑所有格式的“万能可写 AST”；
- Word、PDF、图片或压缩包标准的替代品；
- 让 AI 推测冒充源文件事实的许可；
- 静默覆盖原件的机制；
- 由某个模型、agent 或应用独占的协议；
- 在一致性测试和独立采用出现之前，就靠宣传自称的“标准”。

这些边界让核心足够小，真正能实现；也让它足够严格，值得信任。

## 邀请

我们邀请预览器作者、解析器维护者、agent 开发者、文档工具团队和普通用户，用真实文件挑战这
套模型：贡献失败样例、竞争实现、安全案例、测量数据，以及更简单的设计。兼容比控制更重要，
证据比口号更重要。

长期目标很简单：**任何文件，都能在不牺牲原件的前提下，成为人与其所选择 AI 的安全共享工作
台。**

对于建立在这套思想上的产品：

> 文件打不开，先用叠象。圈出哪里要改，让任意 AI 生成下一个版本。
